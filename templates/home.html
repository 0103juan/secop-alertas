Observatorio II · Backend API

SECOP alertas

Alertas y lecturas analíticas sobre la contratación pública de Colombia (SECOP II, datos abiertos). Desarrollado con Django + Django REST Framework, PostgreSQL, Redis y Pub/Sub sobre Cloud Run. Las lecturas describen patrones en los datos; no juzgan a ninguna entidad.

  • Documentación interactiva (OpenAPI / Swagger)
    Registro, autenticación JWT, suscripciones y entrega de alertas.
  • /api/v1/contracts/?q=vías
    Búsqueda de texto completo en español con paginación por cursor y filtros por modalidad y valor.
  • /api/v1/analytics/splitting/
    Posible fraccionamiento: ventanas de contratos de una entidad con un mismo proveedor que juntos superan un umbral. Algoritmo O(n log n).
  • /api/v1/analytics/outliers/
    Valores atípicos por modalidad y tipo (estadística robusta con mediana y MAD, SciPy).
  • Código fuente en GitHub
    Arquitectura, decisiones técnicas, benchmarks y suite de pruebas en el README.
Datos abiertos oficiales de SECOP II (Colombia Compra Eficiente) en datos.gov.co.
